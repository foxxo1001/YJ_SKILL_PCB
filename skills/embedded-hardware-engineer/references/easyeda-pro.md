# 嘉立创EDA专业版

读取项目文件时先确认本地 `.eprj3` 索引与配套的 `sch/`、`pcb/`、`panel/` 文件。索引里出现多块 PCB 时，使用用户指定的板名或 UUID。未选择单一目标时先列板名让用户确认。

- 通过 Skill 启动器运行 `review full <项目目录或 .eprj3> --pcb "<板名或 UUID>"`。唯一 PCB 可以省略选择参数。
- 原生检查在隔离副本中运行，需本机嘉立创客户端的 CLI 已连接。核对报告的 `target`、原理图页、规则状态与证据路径。工程含独立 PCB 时，原理图检查须有明确的配对页。
- 嘉立创原生结果会按规则和网络分组。报告引用原始对象 ID、层、网络和可核对的位置。若坐标单位无法证实，保留原始值并注明。
- 原生服务受阻时，保留规则检查的受阻状态，可请用户启动嘉立创专业版客户端后复验。`--offline` 可只读提取受支持的矩形板框、位号、焊盘网络映射、直线走线段和过孔。铜面连通、参考面和装配需要各自证据。
- 若客户端改写审查副本，按 `checked_snapshot_status` 描述副本的实际结果，原始版本保留待核验。报告的 `session_receipt` 记录变动文件和保留的副本。报告缺少关联证据时，说明当前判定只能覆盖哪些对象。
- `schematic_parity` 对照同一项目内的单个关联原理图页与所选 PCB 的原生网表，按位号、封装标识和针脚网络定位差异。报告中保留两份工具原始输出。多页与层级原理图需要明确页作用域，当前标为待核验。
- `design verify <项目> --pcb "<板名>"` 额外导出所选 PCB 的原生 BOM，校验位号、分组数量和采购料号，保留原始 TSV。BOM 的采购校验仍需采购源和数据手册。

## 生成新板和审批改版

- 用户给定外形尺寸、焊盘 XY、网络、线宽、净距和边缘距离后，用 `design generate <规格.json> --output <新目录>` 生成嘉立创原生 PCB。规格要求 `width_mm`、`height_mm`、`edge_mm`、`gap_mm`、`pad_mm`、`trace_mm` 和 `nets`，其中每个网络两端各填一组 `[x, y]`。坐标从板框左下角起，单位 mm。当前适用单面铜的独立测试焊盘、简单转接板，出图后读回原生 DRC。多层布线、器件摆放和自动原理图属于后续能力。
- 从已审查的板上找出受影响的走线对象 ID。可用 `change propose --project <项目> --pcb "<板名>" --edits <变更.json>` 预览线宽变更，JSON 的 `trace_width_mm` 是走线 ID 到目标线宽的映射。也可以用 `--replacement <独立的同 UUID .epcb2>` 提交完整 PCB 候选。说明变更位置、原因、原始哈希、候选哈希、影响项和复验条件。
- 只有收到用户对这条提案的明确批准后，才记录 `change decide <提案ID> approve --project <项目> --reviewer <审批人> --reason <批准范围>`。随后用 `change apply <提案ID> --project <项目>` 提交工作副本并复验。拒绝时记录 `deny`。用 `change rollback <提案ID> --project <项目> --reason <原因>` 生成独立的基线工作版本并复验。原件覆盖、制造和上传需要单独授权。
