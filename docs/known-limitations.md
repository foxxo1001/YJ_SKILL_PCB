# 已知限制

- 发布工件为 0.1.0 read-only-preview。独立金标准质量门禁和 PRD core 发布门禁分别记录。
- 工程模型以用户提交的适用条件、数据手册限值、布线几何和报价为输入。测量型需求保持 not_run 或 inconclusive，现有包没有真实试验数据。
- KiCad 原生规则检查按项目自身规则运行。原生工程的规则排除项在支持报告字段时显示。E3 的焊盘相对坐标、部分铜区和层对象只能证明相应解析数据。
- 机械使用三轴包络，支持将线束弯曲、螺丝刀和插配空间作为输入。没有 STEP 实体、公差链的 CAD 运算或热/结构/电磁场仿真。
- 回流与 EMI 需要真实参考面和几何绑定。PI 使用离散频点，SI 采用简化无损线路，保护使用声明的 DC 源模型。
- Markdown/PDF 解析输出候选和出处。跨表、扫描 PDF、多附件规则关联、评分语义和赛题规则版本需独立复核。
- 工作副本写入限为批准的单文件 KiCad 替换。批准必须绑定原始输入和补丁哈希。原始工程、仪器、采购及制造没有执行路径。
- 隐藏评测架构需要独立人员维护目录权限和源分组。随附 36 个开发 gold 可重跑。近重复指纹无法覆盖大改写、翻译和跨格式语义重复。
- 在继续工程增强时，优先采集电源瞬态、结温、装配包络和真实赛题的独立验收数据，再用已明确许可的样例验证嘉立创EDA/Altium 原生规则，建立私有 holdout 并执行跨平台测试。
