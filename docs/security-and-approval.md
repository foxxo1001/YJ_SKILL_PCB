# 安全与审批

- 默认读本地输入。KiCad 原生检查使用临时副本，报告通过受约束的 .ehe 路径保存。运行命令固定为 ERC/DRC，采用参数向量，保持原生输入哈希。
- workcopy_replace 预览统一 diff。审批绑定目标和替代文件哈希、工程输入快照、变更作用域，并记录复核人和理由。输入变动后需要重新生成和重新审批。
- 获批后唯一写入的是 .ehe/work 下的版本化工作副本和状态文件。原子发布与内容收据防止进程恢复时重复发布。同一文件名必须同类型，限制为符合语法的 KiCad .kicad_sch/.kicad_pcb。
- 原始工程写入、仪器、烧录、上电、采购、制造发布和第三方上传均没有可执行路径。审批被拒绝会停在 PAUSED。
- 用户名文本是本机审计元数据。本机目录 ACL 与宿主工具权限控制谁能执行审批。需要针对不可信执行者独立审查时，由不同 OS 账号管理副本和评测，控制运行目录和金标准读权。
- EDA CLI 是平台本地进程，临时副本提供工程文件隔离。用户处理不可信原生 EDA/PDF 等文件时可在单独受限账户或系统沙箱运行。
- 导入知识保留授权和出处；资料中的命令是文本。隐藏集由独立评测端保管，仅向知识导入端提供去重指纹。
