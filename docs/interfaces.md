# 接口、模型与评测

## 工程输入

`project.json` 可指向实际原理图、PCB 和工程模型，路径均相对于工程根目录。
每个计算输出状态、指标、发现、缺失字段和文件证据。字段单位写在名称中，金额口径由数据声明。
[完整模型样例](../examples/engineering-model/engineering.json) 提供参数和正确基准，可以逐项换成可核查输入。
通用报告格式接受 `{"format":"ehe-rule-report-v1","violations":[{"type":"…","severity":"…","description":"…"}]}`。
统一 JSON Schema 的类型定义位于 [ehe.schema.json](../schemas/ehe.schema.json) 的 `$defs`。

| 领域 | 建模与关键条件 |
|---|---|
| 电源、引脚、BOM | 峰值电流与项目填入的能力比较，电平限值需要来源，位号大小写归一后检测冲突 |
| 机械 | 同坐标系内 AABB，元件、板框和插配扫掠外扩，壳内空间收缩，计算裕量及干涉 |
| 热 | 结温估算为最高环境温度加总损耗乘有效热阻，导通损耗采用热态电阻和 RMS 电流 |
| 电池瞬态 | 低荷电开路电压减峰值电流乘总电阻，附加电容支路只用于声明为独立的增量压降 |
| 公差 | 阻值有界精度及温漂生成分压边界，未拟合随机分布 |
| 能耗 | 六状态的典型输入功率按占空比加权，含外围静态电流、分状态效率与输入静态功耗 |
| 采购 | 按数量/MOQ 选价格级别，汇总成本项与最长交期，关联日期、货币和报价出处 |
| Pareto | 先按带来源的硬约束筛选，按所填目标求非支配解，未知量单列 |
| 精密模拟 | 共模和摆幅、正弦压摆率、闭环设计带宽、单极点半 LSB 建立和绝对误差 |
| 电机和 Buck | 冷态堵转及持续时间 SOA，热损耗限值，连续导通理想 Buck 的最坏纹波 |
| 短路 | 电阻型 DC 故障上下界、常电流 I²t，保护曲线缺少时不合格状态保持待验证 |
| 回流、EMI | 栈叠与人工绑定的真实参考区域、中心线穿缝与换层耦合，开关差分路径投影面积 |
| SI、PI | 指定端接电阻的一次反射与传播延时，离散频点并联 RLC 的 PDN 阻抗 |
| 实时性 | 串行最坏阶段耗时与抖动累积，含编码开销的通信吞吐筛查 |

## 知识

清单须含 `source`、`revision`、`accessed_on`、`rights`、`group`、`year`、
`track`、`role`、`kind`。显式选择角色官方、作者主张、已独立复核或未核实。
录入结构化 claims 时需要实体、参数、值、单位、工况及确切定位符。冲突即使含官方来源仍输出
`requires_applicable_official_recheck`，保留版本和定位。跨版本、跨工况引用需人工确认。
KiCad 文件可建立原生对象索引，PDF 带页/行，CSV BOM 带行号。机械模型及无可读文本文件仅留档案身份。
资料保留原文件路径和 SHA-256，本地数据库不复制整个原文件。原始数据与校准记录应另存。
隔离清单是 JSON 数组，每项至少有 `path`、`group` 和 `partition: hidden_holdout`，
路径相对评测清单。近重复使用三词 shingle 的 SimHash，跨语言、重写或大幅增删需评测方复核。

## EvalOps

公开 36 项开发金标准保存在 [core.json](../src/ehe/data/gold/core.json)，分离输入与期望工具输出。
使用 `ehe eval run --suite core --output <new.json>` 重跑。原生 AT25 调用 KiCad，
AT30 在独立进程强制中断，AT32 测试近重复隔离。报表的 case ID 对应 PRD 验收，
记录实际观测、判分差异、输入哈希、工具和运行版本、重复波动。`--baseline` 要求相同语料
与工具版本并检查已通过项退化。`--suite-file` 支持评测方持有的同协议用例清单。
公开开发集规模无法代表任意工程；P0 检出、诊断精确率和数值正确率仅适用于报告所列样本。
质量门禁低于发布门槛时阻止发布。正式发布另需 PRD 全部核心条件和独立人工放行。
