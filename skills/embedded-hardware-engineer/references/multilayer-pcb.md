# 多层板设计与复验

多层整板审查和新板布局使用本流程。局部整改从受影响的网络、铜区、参考面和热通道切入。单面或双面板上的大电流、快边沿和局部热问题也可用对应条目。

## 1. 先确认约束和数据

读取当前 PCB、原理图、板厂叠层和工艺规则。以实际网络、走线、焊盘、过孔和填铜为证据。先确认铜厚、参考层、峰值及持续电流、允许压降和温升、器件手册的布线和散热要求。遇到外壳限高、插拔、开槽或天线，标出具体层和禁区。

为每条关键网记下**两端位号与焊盘、工况、约束与来源、实际值、裕量、证据位置**。分段要求优先写到具体端点或区域，便于出脚段和主干分别验收。

| 约束 | 应确定的条件 |
|---|---|
| 线宽 | 允许的最窄铜宽及适用长度。大电流用始动、堵转或持续电流、有效铜厚和允许压降/温升核对。受控阻抗用板厂叠层定对应层的线宽和间距 |
| 线长与时序 | 明确检查哪两个焊盘之间的路径。按接口要求检查最大长度、差分对内偏差或组内延迟。走线含圆弧或换层时按实际路径计入，缺传播模型时给几何长度和未核验的延迟 |
| 位置与层 | 写明允许层、参考面、必须经过或避开的区域及换层位置。功率、敏感采样、时钟和高速接口分别设置 |
| 铜与过孔 | 明确网络、层、铜区用途、优先级和最窄连接要求。记录关键过孔的用途、允许孔型、实际连接层和制造要求 |

关键约束以产品需求、器件手册、计算或板厂资料为来源。缺数据时把测得的几何和待确认的限值分别记录。未知的关键约束保留为待核验。 [嘉立创设计规则](https://prodocs.easyeda.com/cn/pcb/design-design-rule/) · [信号时间等长](https://prodocs.easyeda.com/cn/pcb/design-time-equal-length/)

## 2. 定布局，布关键线

先固定板框、装配件、接口和禁区。把旁路电容、驱动器、电流采样和需要热扩散的器件摆到能实现预定路径的位置。为回流地过孔、散热过孔和铜区预留空间，再处理输入旁路、功率开关、敏感采样、时钟和高速信号。

- **信号回流。** 沿关键线路核对相邻参考面连续性。指出跨缝、开槽、平面边缘和过孔密集区造成的绕行。换层前后参考不同的同网 GND 平面时，核对附近回流地过孔在哪、跨哪些层、两张地面是否在重铺后真正接上。距离和摆法按接口或器件的要求。若参考面换成不同网络，优先调整走线或选层以保持参考连续，确需换参考时补充有效的高频回流路径和验证依据。 [TI 高速信号布局指南](https://www.ti.com/lit/an/slla414a/slla414a.pdf)
- **功率回流与铺铜。** 按实际开关状态追踪电流从旁路电容到功率级、再回到电容的路径。检查相邻信号的共享回流、铜颈、热焊连接和并联过孔瓶颈。给大电流铜区留宽度和连续性，按器件建议控制高 dv/dt 开关节点的铜面积。ADC 原始采样和参考路径避开功率开关回路。 [TI 电机驱动布局指南](https://www.ti.com/lit/an/slva959b/slva959b.pdf)
- **散热。** 从裸露焊盘或指定热接口追踪到过孔、内层/底层扩散铜和最终散热边界。核对散热焊盘电气网络、孔径/数量/接层、焊盘内孔的装配处理及分割或细铜颈。按损耗和壳内环境估算最坏工况的热裕量，并给样板测温点。地过孔兼作散热孔时分别验证它的回流位置与热出口。 [TI PCB 散热设计说明](https://www.ti.com/document-viewer/lit/html/SLVAEI9/GUID-E5117FAB-46FE-42C2-AEC7-1DD13B266C80)

核对关键路线后锁定走线、过孔和锚点。自动布线仅交给明确允许的网络。工具无法限制网络范围或保护锁定对象时，改为手动或局部交互布线。在工作副本对照布线前后的关键对象和约束。走不通时报告冲突的位置和选择，例如移固定孔旁的连接器，或调整供电路径。保持已知硬约束并列出尚未完成的网络。

## 3. 用实际填铜复验并交付

在新设计或获批副本重建铺铜。检查填铜多边形的实际连续性、最窄截面、孤岛和有效连接到的焊盘、热焊辐条、过孔。已有工程只读审查时使用对应修订的填铜证据。重铺或改走线后复跑原生 DRC，并复查关键网长度、局部铜宽、参考面连续性、回流过孔和散热路径。 [嘉立创铺铜与重建](https://prodocs.easyeda.com/cn/pcb/place-copper-region/)

运行器的几何是原生对象子集。嘉立创适配器可读取部分走线、过孔和焊盘网络，目前的标准几何输出缺少实际填铜形状和完整的焊盘坐标变换。要确认平面或热通道时，从编辑器或可追溯的导出补齐叠层、孔实际接层、填铜和相关端点。使用 `review full --model` 时，回流模型的结论仅覆盖提交的走线、参考面缺口和换层数据。把缺证据标为待核验，分别记录原生检查、几何审查、模型估算和样板实测的结果。

报告每条问题使用**网名、层、坐标或对象 ID、实测或计算值、限值、影响、改法和复验**。温升及 EMC 的验收保留实物工况和通过判据。

扩展或验证 Skill 能力时，在独立测试板副本上逐一缩窄供电铜、把采样线挪近开关区、切开参考面、删除回流过孔或隔断散热铜。用同一板的正确版本对照，重铺并核对这些问题能否被定位、恢复后能否通过复验。
