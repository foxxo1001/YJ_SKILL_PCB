# 新板设计与验证

从 [设计输入表](../assets/design-brief.md) 建立约束和通过阈值。根据实际任务裁剪表格。可先读取已有文件，用来源清晰的可逆假设推进探索，在元件和布局选择依赖关键数据时向用户追问。写明已选方案、主要取舍及证据。

1. **方案。** 用明确工况算输入、峰值电流、温升、采样误差与机械余量。确定电源树、保护、接口、参考地、启动状态及调试点。完整料号要核对厂家推荐工作条件、引脚表、封装厚度、最大部件尺寸和参考设计。
2. **原理图。** 创建同名的原生 KiCad 工程与原理图。结合本地已验证符号/封装和适用手册，连接电源、接口、采样、保护、复位、连接器与测试点。逐脚核对符号与 PCB 焊盘，显式标记允许悬空的引脚。关键器件填 MPN 和证据引用。保存可追溯、可打开的原生工程，再跑 ERC。
3. **PCB。** 先设机械基准，放固定孔、对外连接器、禁布和可达空间，再确定层数、参考面、规则及高速网类。先布输入旁路与功率开关电流路径，再布敏感模拟、时钟和主接口，检查去耦、参考面连续性、热扩散、测试点与插拔空间。落实走线、覆铜与约束并检查连接关系。
4. **交付。** 将 `.kicad_pro`、`.kicad_sch`、`.kicad_pcb`、所需本地库和 BOM 放在一个新目录中。执行 `design verify <project>`。用实际 KiCad 检查 ERC、DRC 和原理图/PCB 一致性，并留存原生 BOM。审阅 `eda_status`、`handoff_status` 和 `coverage`。逐项给出设计约束、证据和剩余风险。板框 CAD、EMC、实测掉压和温升各自留证据。

优先使用能产生原生文件的 EDA 工具。若采用脚本生成或改写，先用目标 KiCad 版本的现有原生文件确认语法、库、原理图位号和 PCB 层号，再在新目录创建，逐次运行解析和原生规则。图纸或页面图不能代替原生工程与板级验证。已有工程的改动遵循授权范围与版本化副本。
